Interactive Linux Command Line Course & Cybersecurity Training

Welcome to CLI Quest: Cyber Citadel, an interactive Linux terminal tutorial. Learn Linux commands, directory navigation, Bash shell scripting, and Capture The Flag (CTF) cybersecurity skills through hands-on practice.

  • Linux File Reading: Master cat, inspect text contents, and view file streams.
  • Directory Navigation: Master pwd, ls, ls -a, and cd.
  • Text Processing & Search: Search logs with grep, count lines with wc, view line ranges with head and tail, and filter output with sort and uniq.
  • File Inspection & Discovery: Inspect file magic bytes with file, find files recursively with find, and decode data with base64 -d.
  • Permissions & Ownership: Understand Linux file permission modes (chmod 755, chown), SUID flags, and world-writable risks.
  • Networking & Admin: Analyze active sockets with ss -tuln, test ICMP ping, view processes with ps aux, and analyze system logs with journalctl.
